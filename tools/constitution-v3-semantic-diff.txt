# constitution-v3-semantic-diff.txt — semantic rewrite manifest for the
# current release
#
# Purpose: the mechanical evidence required by §17.8 "生效范围" condition ③ —
# after every applicability marker is stripped from the Chinese text of the
# release under test, the result may differ from the previous release (v2.10.0)
# only inside the ranges declared below.  Read by
# tools/check_constitution_text.sh (check C5).
#
# Coordinates: **previous-release line numbers** (the v2.10.0 zh-CN file), not
# the current-release numbers — a declared range says "this part of the old
# text was deliberately rewritten", which stays meaningful after the new file
# grew.
#
# Strip rule used to produce the comparison (do not widen it):
#   1. delete a marker at the END of a line:      s/[ \t]*〔[^〕]*〕[ \t]*$//
#   2. delete a line that is ONLY a marker:       /^[ \t]*〔[^〕]*〕[ \t]*$/
# Never a global 〔〕 deletion: inline examples in the §17.8 syntax paragraph
# (and similar prose) are clause text, not markers.
#
# Format:  <M ids>  <start>-<end>  <anchor + why>
#   M ids   : the modification point(s) of the revision plan that own this
#             range (M1–M40); F<n> = a fix from the Chinese final-text review
#             round; M0 = non-semantic (version string only); R<n> = a range
#             whose only justification is diff realignment — an insertion that
#             re-split hunks already owned by another range — never a rewording.
#   range   : previous-release lines, inclusive, 1-based.
# Sources : task-final-plan/final-plan.md §4 (M1–M40, with zh: line numbers),
#           task-fix-cn-review/fix-report.md (F1–F14 + review round 2).
#
# Change records answer a different question — "what did this release change?" —
# and are verified positively instead of by hunk coverage.  Coverage alone cannot
# say "this section is new here": a hunk is the finest granularity the range
# model has, so an inserted section that abuts a rewritten paragraph shares that
# hunk under any diff alignment.  Records are in NEW-edition coordinates:
#   Format:  <N|X><n>  <line>  <anchor>  — <what changed>
#     N<n> : a clause this release ADDS — <line> must be a heading.
#     X<n> : a line this release REVISES — <line> must not be a heading.
#     <line>   : line number in the published Chinese edition of this release.
#     <anchor> : a distinctive substring of that line.  The check requires it to
#                sit on <line>, to be scope-unique (N: the only *heading*
#                containing it; X: the only *line* containing it), and requires
#                the whole line NOT to occur verbatim in PREV_TAG after the
#                marker strip — an unchanged line is not a change.  A wrong
#                <line> therefore FAILS instead of passing quietly.
#
# Notes on what is deliberately absent:
#   * M6 (whole-document marker pass) contributes NO line to this file — that
#     is the point of the invariant: markers are metadata and vanish under the
#     strip rule, so they can never justify a textual difference.
#   * Marker-only fixes of the review round (F5a, F5b, F6a, F9, F10) likewise
#     leave nothing behind after stripping.
#   * F4a–F4d2, F6b, F6c, F7, F8, F11–F14 land inside the M ranges below; only
#     F1, F2 and F3 needed a range of their own.
#   * Pre-push release fix (RM1): §8.7's "constitution-repository itself"
#     paragraph moved into §17.8 — a 宪自-only obligation cannot sit under an
#     A/B marker (§17.8 "read the marker alone"). The move needs no new range:
#       - source side: the paragraph vanishes from §8.7, which widens the M25
#         hunk from prev line 520 to prev lines 520-522 (the deleted paragraph
#         plus the blank line it left behind) — hence M25 is now 506-522;
#       - destination side: §17.8's new paragraph lands on prev line 1252, in
#         the M3,M5 hunk that already rewrote §17.8's closing paragraphs.
#     The moved paragraph carries no applicability marker, so the marker
#     invariant (80 markers at v3.0.0 / 11 block markers) is untouched by the
#     move.  That count is a record of the v3.0.0 state, not a live
#     expectation: C1 prints the current totals itself and asserts none of them.
#

# declared above — and not a single v3.1.0 edit.
